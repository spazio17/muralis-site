Hang it up,
and leave it.

An Android kiosk launcher for wall-mounted Home Assistant dashboards. It locks the tablet to one page, recovers on its own, and answers to MQTT and HTTP.

  • Android 8 and up
  • Ordinary APK
  • No root
  • MQTT + HTTP
  • Home Assistant discovery

Built to be left alone

Wall panels drift. A browser stops repainting, a blip leaves an error page, an update reboots into the stock launcher.

Locked to one page

Lock task, home app, no reachable system UI. Comes back by itself after a reboot.

Recovers unattended

Failed loads retry, hung loads time out, a killed renderer is rebuilt, and a server back from a restart earns one clean reload.

Catches a frozen page

Reloads a dashboard that was updating and stopped. A page that never changed is left alone.

Restarts itself nightly

A full restart in the small hours, and a dashboard rebuild whenever the device reports low memory.

Automation recipes

Muralis publishes its controls to Home Assistant, so a panel arrives as a device with buttons and sensors. The recipes below are ready-made automations built on them. Import one and Home Assistant asks you which entities to use; there is no YAML to edit unless you want to.

Needs Pro

Wake on presence, blank when empty

A panel that glows all night is a nightlight nobody asked for. This wakes the screen when someone is in the room and blanks it again once the room has been empty for a while. Only the backlight changes, so the dashboard is still loaded and comes straight back.

It asks you for

  • a motion or occupancy sensor
  • the panel's Wake display and Display off buttons
  • how long the room must be empty first
  • optionally, something that keeps it dark regardless

Needs Pro

Keep the battery in a healthy band

A tablet left plugged in forever sits at 100 percent and warms up, and after a year or two the battery swells and lifts the screen off the front. This charges it only between two thresholds instead. The panel keeps running throughout; only the charger is switched.

It asks you for

  • the panel's battery level sensor
  • the smart plug feeding its charger
  • the floor and the ceiling, 20 and 80 by default

Both read the panel's own entities, so both need Pro. Home Assistant imports blueprints from GitHub rather than from any website, which is why the buttons above hand it the repository and not this page.

Requirements

Android 8.0 (API 26) or newer.
Install An ordinary APK. No root, no platform signature.
Full kiosk Needs device owner, over adb or by QR at setup.
Without it Still runs and recovers. System UI stays reachable, reboot unavailable.
Google account Only to buy Pro.
Dashboard Any web page, internet or local.
Broker Only for MQTT. Unencrypted, so trusted networks only.

Availability

Runs on real hardware daily. Not published yet, and nothing here to download.

Pre-release. The app is signed and running on real panels. The download and the provisioning QR arrive with the first public release: the QR pins the certificate the app is signed with, so it can be published once and then never changes.
